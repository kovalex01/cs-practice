Команда git diff показывает изменения между двумя состояниями
Команда git show отображает один объект, чаще всего коммит, и выводит его метаданные (автор, дата, сообщение) вместе с изменениями, которые этот коммит внёс.
Команда git log -S ищет коммиты, в которых изменилось количество вхождений указанной строки
Команда git blame работает не с историей в целом, а с текущим файлом: для каждой строки она показывает, какой коммит последним её изменял, кто автор этого изменения и когда оно было сделано

git restore-превращает файл в последний коммит
git restore --source... при указании параметра превращает файл в коммит с номером этого параметра
