Рабочая папка-каталог текущих проектов
Индекс- место где хранятся черновики существующие только на компьютере и еще не занесенные в постоянную историю проекта
Коммит-снимок файлов навсегда занесенный в историю репозитроия
Git-система контроля версий, позволяющая сохранять историю проекта и возвращатся к его прошлым версиям, а Github-облачное хранилище коммитов которые создаются в Git
###Использованные команды
git status - показывает текущее состояние вашего рабочего каталога и индекса
git diff --staged  - показывает изменения которые уже добавлены в индекс но еще не закреплены в коммите
git diff-Показывает изменения, которые ты сделал, но ещё не добавил в git add. То есть рабочая папка vs последний коммит.
